Datos y almacenamiento

Esta app guarda todo en tu navegador (personal, no se comparte con nadie más). Para trabajar entre varias personas: cada quien captura por su lado y exporta su .json; luego uno de los dos usa "Fusionar" (no "Importar") para juntar ambos sin perder lo propio.

⚠ Este archivo trae datos reales del negocio (NITs, precios, clientes) escritos directamente en el código. Si lo subes a un repositorio público de GitHub (o lo publicas con GitHub Pages en el plan gratuito, que exige repo público), esa información queda visible para cualquiera. Hacer el repositorio privado no alcanza a resolverlo del todo con el plan gratuito de GitHub Pages.
Los datos se guardan automáticamente en tu navegador.
